# 🪷 Chùa Linh Ứng Online — TikTok Live RPC (9:16 Interactive Buddhist Sanctuary)

Hệ thống phát trực tiếp tương tác (**Interactive TikTok Live Stream & JSON-RPC 2.0**) chuẩn khung dọc **9:16 (`1080×1920`)** dành cho **OBS Studio / TikTok Live Studio**, chạy siêu nhẹ trên **Node.js** hoặc **Bun.js** mà **không bắt buộc phải cài Python hay môi trường AI phức tạp**. Tích hợp sẵn âm thanh, giọng đọc tiếng Việt Dual TTS (Edge TTS mặc định + ZeroTTS fallback), tương tác quà/comment TikTok Live và chế độ giả lập test trước khi phát live thật.

Người xem trên TikTok Live tương tác trực tiếp qua **Bình luận (Comment)**, **Thả tim (Like)**, **Chia sẻ / Follow** và **Tặng quà (Gift)** để thực hiện các nghi thức tâm linh trên màn hình Chánh Điện **Đức Phật A Di Đà**:
- 🔥 **Thắp hương & Đảnh lễ Tam Bái (8-Frame Walking & Prostration)**: Nhân vật Phật tử bước đi từng bước dọc thảm đỏ hoa sen lên trước Lư Hương Đỉnh Đồng, hạ gối quỳ và thực hiện 3 lạy Ngũ thể đầu địa hướng về Đức Phật A Di Đà.
- 👘 **Đa Dạng Y Phục & Đổi Áo Tự Động (Skin System)**: Hỗ trợ 6 diện mạo Phật tử chân thực (`nam`, `nữ`, `sư`, `ni`, `tiểu`, `bà`). Người xem bình luận từ khóa tương ứng sẽ tự động đổi trang phục và tỏa ánh hào quang.
- 🏮 **Thả Đèn Hoa Đăng / Sớ Cầu Nguyện**: Bình luận lời khấn sẽ bay lên thành Đèn Hoa Đăng kèm giọng đọc AI đọc lời cầu nguyện.
- 🎋 **Xin Xăm / Gieo Quẻ Đầu Năm (Đồng bộ Giọng đọc & Tờ Giải Quẻ)**: Tự động lắc ống xăm và mở tờ Giải Quẻ (Thượng Thượng Cát, Đại Cát, Thượng Cát...) đúng thời điểm giọng đọc bắt đầu vang lên.
- 🪵 **Gõ Mõ & 🔔 Thỉnh Đại Hồng Chung**: Thả tim gõ mõ tích điểm Công Đức, chia sẻ/follow thỉnh chuông đồng lan tỏa sóng âm vàng và kích hoạt làn sóng vái lạy của 40+ Phật tử trong Đạo Tràng.
- 📜 **Bảng Vàng Công Đức (`TẤM LÒNG THÀNH` & 6 Đệm Quỳ VIP)**: Vinh danh trực tiếp người xem thật có điểm Công Đức cao nhất trên 6 đệm quỳ gấm đỏ trước bàn thờ Phật.
- 🤖 **Bộ Giả Lập & Bảng Điều Khiển Live (`/admin`)**: Đầy đủ công cụ test bình luận, quà, xin xăm, thỉnh chuông/gõ mõ và tạo nhanh 15–40 Phật tử ngồi kín đạo tràng để xem trước màn hình live.

## ⚡ Kiến Trúc & Tối Ưu Hóa Hiệu Suất (Siêu Nhẹ CPU/GPU)

- **Dual TTS Engine (Edge TTS mặc định + ZeroTTS fallback)**:
  - **Mặc định (Out-of-the-box)**: Sử dụng **Microsoft Edge Neural TTS** (`vi-VN-NamMinhNeural` / `vi-VN-HoaiMyNeural`), chạy trực tiếp từ Node.js/Bun.js không cần cài Python, không cần GPU, tổng hợp giọng tiếng Việt tự nhiên và lưu cache mp3 tức thì.
  - **Dự phòng cao cấp (ZeroTTS)**: Tự động phát hiện và kết nối với `tts_worker.py` (model `zeroweight-ai/ZeroTTS`) nếu máy chủ có môi trường Python `.venv`. Chuyển đổi linh hoạt giữa 2 engine qua API/Admin Panel.
- **Runtime**: Hỗ trợ đầy đủ cả **Node.js** (`>= 18`) lẫn **Bun.js** (`>= 1.1`).
- **Canvas Particle Engine (`public/js/particles.js`)**:
  - Khóa tốc độ vẽ ở **30 FPS** ổn định, tự động tạm dừng khi ẩn tab (`document.hidden`).
  - Pre-render toàn bộ Khói hương, Hạt vàng và Cánh hoa sen ra Offscreen Canvas 1 lần duy nhất lúc khởi tạo (`drawImage`), không gọi `createRadialGradient` hay `shadowBlur` trong vòng lặp frame.
- **Zero-Flicker Sprite Stack & Đa Dạng Nhân Vật (`public/js/live.js` & `public/css/live.css`)**:
  - Nạp sẵn cả 8 khung hình chuyển động (`walk1`, `walk2`, `kneelDown`, `kneel`, `forehead`, `bowMid`, `prostrate`, `prostrateDeep`) và 6 bộ skin nhân vật (`c_man`, `c_woman`, `c_monk`, `c_nun`, `c_child`, `c_granny`) vào GPU.
- **Bộ Lọc Chặn Ký Tự Lạ & Spam (`server.js`)**:
  - Chặn tự động các ký tự Cuneiform (`𒐫`), chữ Ả Rập gây lag, Braille, Zalgo, bình luận chỉ toàn dấu chấm (`...`) hoặc từ ngữ phản cảm.
  - Tự động chuẩn hóa Unicode (`NFKC` → `NFC`) chuyển tên kiểu chữ toán học về tiếng Việt sạch trước khi đọc TTS.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Nhanh

### Cách 1: Chạy ngay với Node.js (Khuyên dùng, không cần cài Python)
```bash
# 1. Cài đặt thư viện Node.js
npm install

# 2. Khởi chạy Server
npm start
# Hoặc chế độ dev reload:
npm run dev
```

### Cách 2: Chạy với Bun.js
```bash
# 1. Cài đặt thư viện
bun install

# 2. Khởi chạy Server
bun start
# Hoặc:
bun run dev
```

*(Tùy chọn nâng cao nếu muốn dùng ZeroTTS local Python)*:
```bash
uv venv .venv
uv pip install --python .venv/bin/python zerotts pillow
```

Mặc định server chạy tại cổng `3000`:
- **Màn hình Live + Điều khiển nhanh**: [http://localhost:3000](http://localhost:3000)

## 🔌 Giao Thức JSON-RPC 2.0 (`POST /rpc` & `ws://localhost:3000/ws`)

Bạn có thể gọi trực tiếp từ **TikFinity**, **Streamer.bot**, webhook hoặc `curl`:

```bash
# 1. Thắp hương cầu an
curl -X POST http://localhost:3000/rpc \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "temple.burnIncense",
    "params": {
      "user": "Thí Chủ Minh Tâm",
      "count": 3,
      "wish": "Cầu gia đình bình an, vạn sự cát tường như ý"
    }
  }'

# 2. Xin xăm / Gieo quẻ đầu năm
curl -X POST http://localhost:3000/rpc \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 2,
    "method": "temple.drawFortune",
    "params": {
      "user": "Thí Chủ Minh Tâm",
      "topic": "Cầu tài lộc và gia đạo bình an"
    }
  }'

# 3. Kết nối tới phòng TikTok Live (@username hoặc link vt.tiktok.com)
curl -X POST http://localhost:3000/rpc \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 3,
    "method": "live.connect",
    "params": {
      "username": "@zenfacts_vn"
    }
  }'
```

### Danh sách JSON-RPC Methods hỗ trợ:
- `temple.getState`: Lấy toàn bộ trạng thái Chánh Điện và Bảng Vàng Công Đức.
- `temple.burnIncense`: Thắp nhang & bước lên đảnh lễ (`user`, `avatar`, `count`, `wish`).
- `temple.sendPrayer`: Thả đèn hoa đăng cầu nguyện (`user`, `avatar`, `wish`).
- `temple.drawFortune`: Lắc ống xăm & gieo quẻ (`user`, `avatar`, `topic`).
- `temple.strikeWoodenFish`: Gõ mõ tích công đức (`user`, `count`).
- `temple.ringBell`: Thỉnh Đại Hồng Chung (`user`, `count`, `wish`).
- `temple.offerGift`: Dâng lễ vật (`user`, `giftType`: `lotus` | `fruit` | `lamp` | `dragon`, `coins`, `giftName`).
- `temple.grandCeremony`: Kích hoạt Đại Lễ Kim Long Chầu Phật (`user`, `coins`, `giftName`).
- `temple.skin`: Đổi trang phục Phật tử (`user_id`, `skin`: `man` | `woman` | `monk` | `nun` | `child` | `granny`).
- `temple.fillBots` / `temple.clearBots`: Tạo 15–40 Phật tử giả lập ngồi kín chiếu / Xóa danh sách giả lập.
- `temple.setBots`: Bật/tắt tự động giả lập luồng tương tác (`enabled`, `count`, `pace`).
- `temple.speak`: Phát giọng đọc TTS trực tiếp qua Edge TTS / ZeroTTS (`text`, `voice`, `engine`, `pitch`, `rate`).
- `temple.ttsStatus`: Kiểm tra trạng thái hoạt động của Edge TTS và ZeroTTS.
- `temple.updateSettings`: Cập nhật âm lượng nhạc nền (`musicVolume`), giọng đọc (`ttsVolume`), engine TTS.
- `temple.resetMerit`: Đặt lại bảng thống kê Công Đức.
- `live.connect` / `live.disconnect`: Kết nối / Ngắt kết nối phòng TikTok Live.
